## 从 OpenClaw 说起

今年初 OpenClaw 爆火。

那时寒假放假在家，刚把要紧的事忙完，整天闲着没事整理自己的 GitHub 仓库。直到二月末我才了解到这个项目。
我跟着官方文档在自己的电脑部署了一个 OpenClaw 。一开始我并不想买 token 来接入龙虾，因为感觉那些 token 实在是贵，它对于我来说又不是必需品。（然而后来证明我可太需要它了）于是又学着使用 ollama 本地部署了一个 Qwen3.5-8b 小模型。不知为什么，单纯使用 ollama 进行对话是没有问题的，速度很快。但是当我把它接入 OpenClaw 之后，每次对话都要花上十几分钟才能出结果，有可能是我的显存太小了。（笔电男大的 4060 8G QAQ）  
另外，我想要让他自己操控鼠标实现网上那种完全自己工作的效果。但是由于当时的我对这方面并不了解（虽然我很早就开始用 AI 辅助编程，但是关于 agent 我只浅浅的用过 Cursor，迫于免费额度太少而弃用），怎么搞都没有效果。最终消耗了两天的精力弄出来一个什么都干不了还慢的要死的 agent，于是我又把它卸载了。后来直到开学后的三月份我都没有再尝试和钻研过 OpenClaw，因为又忙起来了。

## 尝试 Claude Code

> ***多年后，面对 Opus 47， Rito-492 将会想起第一次让 Claude Code 帮他重构项目的那个遥远的下午。***

清明假期，又是把该忙的忙完了，又是闲着没事。心血来潮想试试 Claude Code。其实是在前几天在闲鱼偶然看到有卖 Claude Sonnet 4.6 的 token，发现可以按使用量计费于是买了几块钱的。直到放假了才想起来，为了不浪费那几块钱，跟着教程安装了 Claude Code ，并且接入了中转的 API。
我想试试他到底能够干什么，于是让他帮我把刚刚做完的一个项目重构一下。  
一开始我还在恼火为什么会有这么多的授权申请。但是当我最后看到成果的时候，我感觉头脑眩晕，瘫坐在椅子上，就像看到原子弹爆炸。（套公式就是快）我终于意识到 AI 代替程序员并不是我曾经想象的相对遥远的将来，而是当下，正在进行着。如果我不持续的学习，如果我不投入对于 AI 的研究而是研究一些其他方向的东西，我毕业即失业。我当时是这样想的。

之后的几天里我近乎疯狂的寻找各种 API，尝试接入各家 LLM。我先后尝试了 sonnet、longcat、qwen、glm。到了现在，我接的是 deepseek v4 pro，简直太香了，性价比夯爆了。（梁圣的恩情还不完ヾ(\*´∀ ˋ\*)ﾉ）

## 从绿群到 AstrBot 再到博客建站

是的，我还没说到正题，因为我想把整个过程记录下来。

学期初，想看看保研信息突然发现被绿群踢了，原来长时间不说话会被踢掉 QAQ。申请进群后发现有个叫**夕颜**的群友很活跃，一开始我以为是真人，挺可爱的一个女孩子。后来才发现竟然是一个是个群主搞的机器人，人设还是个xnn。。。
后来有一天和高中同学聊天突然想搞一个类似的机器人拉进同学群里玩玩。折腾了好久才知道夕颜是 AstrBot + NapCat实现的，因为我只能和 AI 对话得出方案，但是一开始 AI 并没有给出这个方案。于是在网上搜索 AstrBot 的一些经验贴，竟偶然找到了大佬群主**阿汐**的博客文章，介绍了夕颜是如何炼成的。[这是大佬的博客](https://axi404.github.io/)，感兴趣的朋友可以去看看，我从中受益颇多。

看了阿汐的博客我产生了创建一个自己的博客的念头，这个念头在蹦出来后一直在我脑袋里萦绕了几天，虽然我当时还没想好应该写点什么内容，但是我决定这么做了。然而我不会前端，对前端了解很浅，所以只能全靠 Claude Code。这就是为什么我要以 Claude Code 开篇，没有 Claude Code 就没法诞生这篇文章。这整个网页都是 cc 帮我实现的，我只负责监督他（实际上只是yesyesyes...），然后根据效果再给他修改的要求。这对我来说是真正意义上的 **vibe coding**，因为我完全不会写前端。

于是这个属于我的个人博客出现了。

## 到底什么是博客？

关于我如何创建我的博客已经聊完了。
但是我还想聊聊另一件事：到底什么是博客？

我记不清是什么时候知道的 **"博客"** 一词了，大概是第一次知道微博的全称是 *"微博客"* 的时候。博客是什么意思呢？我原本只知道是单词 **blog** 的音译，但是这个词是怎么来的我其实一直不知道。直到前几天我才去详细了解了它的历史，在这简单引一下维基百科的介绍吧:
> 1997年12月17日，约恩‧巴格尔发明了术语“网络日志”（Weblog）。而“Weblog”的缩写“blog”则是由Peter Merholz发明，当时他在自己的博客“Peterme.com”侧边栏开玩笑地将“Weblog”变成词组“we blog”。  
> 不久之后，埃文·威廉姆斯在Pyra Labs上将“blog”同时作为名词和动词（Blog可以表示博客，也可以表示编写博客。）。并且设计了“blogger”这个词，来做为与Pyra Labs的Blogger链接，最后以此引领了大众。

原来博客原意是网络日记。
